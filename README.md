# Autofill

Short description

## What It Does
PDF → AI extraction → field matching → autofill → manual review

## Features
- PDF text extraction
- AI-powered data extraction
- Form field detection
- Automatic field matching
- Highlighted changes
- Manual review
- No automatic submission

## Installation
Download ZIP
→ Extract
→ chrome://extensions
→ Developer Mode
→ Load unpacked
→ Select folder

## OpenRouter API Key
Create key
→ Open Autofill
→ Paste key
→ Save

## How to Use
1. Open PDF/task
2. Open form
3. Run Autofill
4. AI extracts information
5. Fields are filled
6. Review
7. Submit manually

## Troubleshooting
"No OpenRouter API key found"
Extension doesn't appear
AI extraction fails
etc.

## How It Works
V1 Detect
V2 Read
V3 Extract
V4 Match
V5 Fill

## Important
AI may make mistakes.
Always review before submitting.
